# Roblox Music Uploader

Download the latest installer from [Releases](https://github.com/Svntinel/roblox-music-uploader/releases/latest)
(`RobloxMusicUploader-<version>-setup.exe`). Once installed, the app updates itself.

Unduh installer terbaru dari [Releases](https://github.com/Svntinel/roblox-music-uploader/releases/latest).
Setelah ter-install, aplikasinya update sendiri.

This repository only hosts the installers. The source code is private.
